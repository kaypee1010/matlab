MATLAB Lab / Practical 5

What's a plot, really?

A plot turns numbers into a picture. Two lists of numbers — x and y — become dots. Join the dots, and you see a trend you'd never spot by reading a table.

Watch the same 8 numbers appear as dots, then get connected into a line.

Try it: 2D plot, live

Pick a function and a line color. The plot redraws instantly — this is what plot(x, y) feels like in MATLAB.

Try it: 3D plot, spinning

A 3D plot has one more axis (z). Drag the slider to rotate the surface and see depth — this is the idea behind surf(X,Y,Z) or plot3.

Labels, legends, annotations — why bother?

A plot with no labels is a puzzle. Toggle these on and off and see the difference.

Hands-on: guided steps

Open MATLAB and follow along. Each step builds on the last.

  1. Make some data. x = 0:0.1:2*pi; y = sin(x);
  2. Plot it. plot(x, y)
  3. Add labels so anyone reading it understands the axes. xlabel('x (radians)') ylabel('sin(x)') title('A simple sine wave')
  4. Plot a second line and add a legend to tell them apart. hold on plot(x, cos(x)) legend('sin(x)', 'cos(x)')
  5. Point out something interesting with an annotation. text(pi/2, 1, '\leftarrow peak')
  6. Now go 3D — a surface plot. [X,Y] = meshgrid(-2:0.2:2); Z = X.^2 + Y.^2; surf(X,Y,Z) xlabel('X'); ylabel('Y'); zlabel('Z')
